# DragonGPT 3.0 完整使用手册

适用：本次审查后的 3.0.0 源码与便携运行包。原安装尚未替换。日期：2026-10-27（Asia/Shanghai）。功能验证范围见[测试结果](DragonGPT_3.0_测试结果.md)，详细能力见[功能清单](DragonGPT_3.0_功能清单.md)。

## 第一章：DragonGPT 简介

DragonGPT 是 Windows 桌面伙伴“霜翎”。固定的 Q 版白龙娘可以陪伴、聊天、做动作、整理你确认的记忆，并提供待办、专注、喝水、电脑状态、剪贴板、文件预览和按需读屏。无需密钥也能使用本地功能。在线回复和云端朗读需要各自的服务配置。

适合 64 位 Windows 10 1809 或更新版本。OCR 需要 Windows 对应识别语言包与系统 Windows PowerShell。完整运行包包含 Qt 依赖；普通使用不需要安装 Qt、Python 或 Node.js。离线大模型语音和本地向量检索是额外组件，运行包不包含环境或权重。

首次使用便携包：解压完整目录，运行 `DragonGPT.exe`。不要只取出 EXE。使用原 EXE 安装器时可选桌面图标和登录自启动；新版审查包没有重新制作安装器，旧安装器不含本次修复。启动后双击桌宠打开陪伴空间；界面有对话、记忆、语音、连接、设置、陪伴、羁绊图鉴、专注陪伴、工具和智能十页。

新安装默认数据位于 `%LOCALAPPDATA%\DragonGPT\UserData`。程序旁已有 `data\memory.sqlite` 时继续使用便携数据；显式 `--data-dir` 优先。升级前退出并备份整个实际数据目录。数据库备份不包含音色、连接、加密凭据等独立文件，完整迁移要备份整个目录。DPAPI 密钥需要原 Windows 用户。

## 第二章：基础操作

| 操作 | 方法与结果 |
|---|---|
| 单击 | 稍等双击判定后，播放符合当前动作和心情的台词；过快连续点击会防抖。选择云声可能联网 |
| 双击 | 打开对话；不会额外播放单击台词 |
| 移动 | 左键按住角色拖动；正常退出保存位置 |
| 菜单 | 右键聊天、识屏、开始语音、镜头、尺寸、置顶、动作和退出 |
| 显示/隐藏 | 默认仅在 Explorer 桌面空白处双击 Q；其他软件内普通 Q 不触发 |
| 更换快捷键 | 智能页改为 Ctrl+Q、Alt+Q、Ctrl+Alt+Q 或 off；注册冲突会提示 |
| 识屏快捷键 | Ctrl+Alt+S，先在智能页授权；失败时用右键或按钮 |
| 设置 | 设置页改称呼、260–680px大小、动画、置顶、半身与动作；半身只是同一角色裁切 |
| 隐藏窗口 | 控制窗口关闭后，有可用托盘时程序继续运行；隐藏桌宠不等于退出 |
| 退出 | 角色右键或托盘选择退出；正常退出写入位置与设置 |

托盘双击打开聊天，菜单可显示/隐藏桌宠、设置、识屏和退出。系统无托盘时不要依赖托盘恢复。隐藏桌宠停止动画帧计算，后台待办和计时仍运行；提醒气泡等待角色可见且展示位置空闲，部分临时提醒会过期。

## 第三章：所有主动功能

### 3.1 主动开场与安静陪伴

作用是偶尔打招呼或提示休息。新建配置默认开启；正常频率每 5–12 分钟评估一次，但还受默认 90 分钟冷却、每日 3 次上限、22:00–08:00 安静时段限制，因此不会每几分钟必定说话。可选安静 15–25 分钟、活跃 3–6 分钟，或关闭。连续忽略开场会延长冷却。

在“陪伴”保存开关、频率、冷却、每日上限、安静时段、勿扰和工作保护。“今天安静陪我”暂停到次日；“恢复主动聊天”恢复。聊天、输入、通话、播放、专注、隐藏、弹窗、已有气泡和受保护动作会暂缓。不开云声时台词选择完全本地；开启云声朗读可能产生 TTS 请求。这里没有自动调用 DeepSeek 编写新台词。

示例：工作时打开勿扰，让她安静待机；空闲时恢复主动聊天。试听开场使用当前音色，不增加亲密度、当日次数或收藏。

### 3.2 情绪与动作

本地规则结合你明确表达的心情、关系、空闲/返回、夜间和专注阶段，形成平静、微笑、开心、思考、好奇、关心、害羞、困倦、难过、生气、傲娇、放松、认真、兴奋等状态。它不是心理诊断，也不是模型读心。状态会保持一段时间并衰减；普通待机变化有滞后，减少闪切。

动画由同一个角色控件仲裁：拖动/点击、正在互动、手动动作、专注阶段、语音、聊天和自动动作按优先关系协作。眨眼、口型、呼吸与过渡复用原图。可在设置或右键关闭动画、关闭随机轮换、预览动作或恢复自动。不需要联网。

### 3.3 关系成长与隐藏台词

真实聊天、单击、完成有效专注会成长。聊天通常 2 点、点击 1 点、合格专注最多 4 点，仍受每日合计 20 点、聊天 30 秒/点击 90 秒/专注奖励 25 分钟冷却等限制。重复聊天、自动开场、试听、跳过和喝水确认不能刷分。专注需实际完成至少 15 分钟，每日最多奖励 4 轮，未达到条件可能没有奖励。

阶段显示为初识、熟悉、亲近、深度羁绊，对应 0/20/50/80% 门槛。百分比同时考虑经验与活跃天数，不能按单次经验简单相加；离开不会倒扣。羁绊图鉴可以看条件、筛选类别/阶段/状态和最近解锁。隐藏台词还可能要求情绪、时间或点击次数。解锁、真正展示、首次听到是三个不同状态。

### 3.4 自动记忆建议与可选学习跟进

默认从短而明确的第一人称偏好、计划、学习近况中产生待确认建议，最多 20 条。示例：“我最近在学习 C++ 多线程”。在“陪伴”确认后才进入长期记忆，也可以忽略。在“记忆”或“陪伴”关闭自动建议；关闭不会删除已保存记忆。提取采用本地规则，不后台调用 AI；疑似凭据和敏感事实会拦截，但检测不能保证完美。

“允许主动跟进学习话题”默认关闭。主动开启后，只用有限主题标签概括学习进展，不朗读原始私人记忆；每天最多一次，同一条记忆至少隔三天。“别再提多线程了”等明确拒绝会停止相应跟进。普通主动台词不直接复述记忆原文。

### 3.5 电脑监测与负载提醒

工具→电脑健康显示 CPU、内存、GPU 和最多 10 分钟趋势。每 5 秒由一个后台监测器采样。GPU/温度依硬件与驱动，缺失时显示不可用；CPU 温度目前不支持。CPU/内存至少 90% 或 GPU 至少 95% 持续两分钟才提醒，同类提醒至少间隔 30 分钟。

示例：感觉卡顿时先看趋势，再看任务管理器。一次高占用不能证明故障。监测本身无需网络；用云声朗读提醒可能联网。当前没有用户界面中的独立硬件监测总开关，程序退出会停止。

### 3.6 番茄钟与喝水

“专注陪伴”填写本轮任务后开始，默认工作 25 分钟、短休息 5 分钟、长休息 15 分钟，每四轮进入长休息。可暂停、继续、结束、跳过、重置、查记录和七日趋势。默认不自动开始下一阶段。设置修改通常从下一阶段生效。锁屏/休眠/调度中断后暂停，重启恢复为暂停，请手动继续；退出期间不算专注。

喝水默认按累计活跃使用 60 分钟评估，专注中优先推迟，返回电脑后还有缓冲。设置中可关闭、改间隔、改经过时间模式或调整朗读/气泡/勿扰。在气泡或页面选“我喝过啦”“15分钟后提醒”“今天不再提醒”。也可说“30分钟后提醒我喝水”；仍遵守保护条件，不能保证精确到秒弹出。提醒不推断实际饮水量或健康状况。

这些功能都可离线运行；云声朗读独立依赖网络。待办、健康、喝水和主动开场会等待现有气泡/受保护动作结束。用户主动请求的番茄阶段提示优先于普通气泡，但仍等待语音、点击、拖动和确认框，避免短计时提示丢失。

### 3.7 待办提醒与每日统计

有时间的未完成待办每秒检查，事务记录已提醒，避免反复提示；退出期间不能提醒，重开后补查。重新打开已完成事项会重置提醒标记，所以再次到期提示是有意行为。

每日总结复用活跃、专注、完成待办、高负载和对话统计。工具→每日总结可刷新、导出文本、手工保存情景记忆；“请 DeepSeek 帮我回顾”会先确认发送。默认没有每天定时自动生成 AI 日报，也不补造程序没运行时的数据。

### 3.8 本地情境与其他后台工作

智能页中的识屏总授权和本地情境开关都开启时，每秒观察活动窗口标题，结合最近五分钟提问及你按需识别的事实，分类编程、学习、阅读、排错、会议、全屏或未知。普通变化稳定约 10 秒，会议/全屏保护优先。不后台截图，不为分类上传标题；分类会作为结构化背景供聊天/计划和防打扰使用。关闭开关即可停止这类信息使用。

其他后台工作包括：情绪到期、专注状态每约 5 秒保存、剪贴板过期清理、已启用语音的分段播放、可选本地模型空闲卸载、日志轮替和单实例控制。它们不是额外的智能代理；具体周期见开发报告。

## 第四章：所有被动功能

### 4.1 对话与连接

离线可试“你好，霜翎”“我有点累”“我完成了”“叫我小林”“记住：我喜欢简洁回复”。离线回复是有限预设，不提供真实通用推理。

联网：进入“连接”，在本机填写 API Key、可用模型 ID、代理方式，勾选启用并保存。密钥输入框留空保留旧值。支持直连、系统代理、HTTP、SOCKS5、用户确认的 TUN；代理失败不偷偷换直连。环境变量 `DEEPSEEK_API_KEY` 优先于加密文件。

发送后可点停止，原消息恢复到输入框。错误会显示来源并可能使用本地回复；本地回复不代表云端请求成功，不自动重发付费生成。复杂模型在智能页设置，留空沿用连接模型。模型列表检查只说明认证/列表读取，不保证余额、模型生成或视觉效果。

### 4.2 语音和通话

语音页选择后立即生效，点试听验证。系统中文使用 Windows 引擎；苏瑶可用内置公开短句、已缓存音频或已准备的离线模型；Audio TTS 使用配置的地域、业务空间、模型、音色和传输入口。云端密钥在语音详情中单独保存。现有音色、缓存和设置不会因审查被重置。

“打字聊天时语音回复”默认关闭，开启也不会打开麦克风。“开始语音”才请求本地中文识别，通过现有聊天服务生成后再用当前音色朗读；可静音、打断/继续聆听、结束通话。中文识别引擎或设备缺失时会提示，文字仍可用。

新建配置“允许备用音色”默认开启：等待超时或失败可能改用系统中文/公开短句，并显示实际来源。要始终保持选择的原声，请关闭该开关；原声失败时停止朗读并显示原因。语速和风格按支持的音色与情绪自动调节，当前没有独立自由语速滑杆。缓存最多约 200MiB，可清空；缓存含你朗读过的文本对应音频，私人电脑请妥善保管。

### 4.3 记忆管理

记忆页输入保存，选中后编辑/双击编辑、删除或搜索。标签含“用户资料”“交流偏好”的记录会在限定数量内用于每轮在线背景，其他内容按相关性检索。可编辑重要性、到期与元数据。相反偏好建议会询问是否替换，不擅自覆盖复杂语义冲突。

导出 JSON 包含档案称呼和记忆，不含密钥/聊天。导入最多 2MiB、1000条，规范化相同内容跳过，保留旧元数据；非法文件整批回滚。“备份数据库”是更完整的 SQLite 备份。恢复需退出后使用 `--restore-backup`，详见开发报告；普通用户应先保留整目录备份。

“清空长期记忆”保留关系、聊天和情绪；设置页“清空本地档案、记忆和聊天”范围更大，确认前阅读提示。两个入口均不能当作完整数据目录清理，待办、剪贴板、专注、独立配置等另有保存。本次审查未对真实数据执行清空。

### 4.4 剪贴板助手

点击桌宠头顶剪贴板展开，首次需勾选记录安全文字。只记录启用后发生的安全文本变化，保留换行、缩进和 Unicode；不记录图像。未固定最多50条，固定最多20条，默认未固定保留24小时，可调1–720小时。关闭记录不删除已有条目。

选中点复制或双击条目，再去目标软件粘贴。复制有系统读回校验、占用重试和状态提示。可固定/取消、删除或确认清空历史，清空不改变系统当前剪贴板。“用AI分析”要求在线、≤1600字，并逐次展示确认；发送后进入正常聊天记录，不能当作临时不留痕读屏。

### 4.5 待办、专注与总结入口

工具→待办可新增、改日期/优先级、完成/重新打开和删除。自然语言框可输入“明天下午三点提醒我复习”，核对有歧义的日期。聊天里的完整命令可直接调用本地功能；智能计划里的待办复用同一编辑器，不再把三天后的日程压成24小时内。

本地命令还包括“现在几点”“今天星期几”“CPU占用率多少”“查看今天的待办”“今日使用总结”“开始25分钟番茄钟”“暂停番茄钟”“番茄钟还剩多久”“招手”“抱尾陪伴”。规则只匹配有限表达，复杂组合请在智能页制定计划。

### 4.6 文件整理与撤销

工具→文件整理→选择自己的下载/文档目录→扫描→逐项核对原文件与目标→确认移动。仅扫描直接子文件，最多5000个；按类型放到同目录 `Organized` 内，不递归、不删除重复、不覆盖同名。隐藏、程序和未知类型保持原位。不是 AI 阅读所有文件后分类。

执行前后核对路径、修改信息与完整哈希；可取消后台操作。失败时尝试回滚，若文件改变可能无法完成回滚，要检查日志。选操作日志后可撤销；原位置被占用或内容变更会拒绝覆盖。智能工具 `files.preview` 只扫描预览，实际移动仍在原页另行确认。

### 4.7 智能页：读屏、资料与计划

读屏：先授权→选择原活动窗口、指定窗口或显示器→选OCR/视觉方式→输入问题→识别。先点击目标再用Ctrl+Alt+S或右键可避免把聊天窗当目标。捕获时暂时隐藏自身窗口并恢复；无法验证、最小化、敏感或安全桌面时明确失败，不偷换目标。默认OCR本地识别；若在线启用，将文字交给模型。视觉模式还会上传本次截图，需要配置支持图像的模型。

结果临时显示60秒，取消/撤销授权会清除；屏幕事实和回答不写聊天或记忆。同图、同问题与模型设置可能命中30秒内存缓存。OCR可能误读代码和公式；请核对原文。屏幕总授权不是无条件读取所有隐私内容，密码/标题规则也可能漏判，私人操作前关闭。

计划：输入“检查电脑为什么变卡，再总结今天的使用情况”→制定计划→检查每步→执行预览中的计划。常见目标本地规划，复杂目标可请求模型。最多8步、9个白名单工具，拒绝未知参数与重复步骤；取消/超时停止后续步骤，已经完成的写入不会自动撤销。重试仅限允许的幂等本地只读工具，付费生成和写入不自动重试。

“总结学习资料”让你选择≤64KB UTF-8文本，核对最多12000字片段再发送；离线只临时显示原文，不能当作AI摘要。不直接解析PDF/Word。剪贴板工具打开原面板，待办打开原编辑器，番茄钟启动原服务，结果里会提示还需你做什么。

## 第五章：智能 AI 系统

DeepSeek用于在线聊天、复杂规划、屏幕/资料文本推理及经确认的总结回顾。当前代码走 `/responses`，生成上限1200输出tokens；历史最多20条消息，背景最多8条用户资料、4条交流偏好、3条相关记忆，单条输入最多2000字。配置模型名不代表服务当前一定开放，需要账户实测。

记忆检索优先可用的本地向量模型，超时/缺失降级关键词。关键词检索会对较旧记忆适度降权。记忆默认不由云端自动抽取，建议需确认，用户主动保存的长期记忆没有自动总量上限。

屏幕像素由一个服务控制；helper负责隔离可能阻塞的Windows捕获，OCR负责提取，ChatService负责模型请求。三者是协作，不是三个后台监视器。智能规划只输出工具计划，不能自己注册新能力。一次只能有一个DeepSeek生成请求占用共享闸门，冲突会提示等待或取消。

AI不能任意运行shell、删除或覆盖文件、修改系统设置、操纵通用GUI，不能知道未被授权的屏幕，也不能代替实际诊断电脑/身体。没有当前普通用户入口的Realtime协议代码属于开发保留能力，不等于已开启OpenAI在线通话。

## 第六章：角色养成

保持自然互动即可。成长同时需要时间与有效互动，短时间重复点按不会快速解锁全部。图鉴中的已解锁不等于已收集；真正遇见台词才记录展示，播放设备开始写入音频才记录听过。试听不增加成长。

右键和设置可选开心招手、害羞傲娇、鼓脸吃醋、抱枕休息、认真工作、抱尾陪伴；基础陪伴使用原立绘。自动轮换会随当前情绪过滤动作，约20–40秒评估变化，专注与互动期间暂停轮换。手动动作结束或点恢复自动后回到调度。没有重绘、成年化或换装功能。

## 第七章：性能与隐私

隐藏角色会暂停33ms动画计时器，本地语音空闲时不再25ms轮询；监测、提醒、情绪与必要状态保存继续运行。可选本地模型按需加载并在空闲时释放。本次性能数值和短时稳定性见测试报告，不能据此承诺多日不泄漏、所有电脑同样占用。

本地数据库保存聊天（最近200条消息，不是200轮）、记忆、关系、情绪、台词记录、待办、统计、专注和按开关记录的剪贴板。独立INI保存设置，DPAPI文件保存密钥，语音缓存保存音频。手工长期记忆、待办历史、API统计和专注记录不会自动全部限量清理，建议定期备份。

在线聊天会发送本轮、有限历史与相关记忆；OCR推理发送识别文字，视觉模式上传截图；经确认的剪贴板/资料/总结分析发送选择的内容；云端TTS发送朗读文本。对应服务商处理这些数据。关闭在线聊天不等于关闭独立的云端音色，需分别配置。

识屏默认关闭，剪贴板记录默认关闭。情境分类不存标题日志，屏幕结果不进入长期聊天或记忆；诊断日志主要记录状态/耗时且屏蔽常见key格式。启发式敏感过滤可能漏判，不能作为绝对保密承诺。备份目录和音频缓存也应按私人资料管理。

## 第八章：故障排查

| 现象 | 检查与处理 |
|---|---|
| AI不回复/变成本地回答 | 看来源和错误；检查在线开关、模型、key、代理；列表成功也不保证生成成功；手动重试会是新请求 |
| 401/403/429/超时 | 分别核对密钥/地域、权限/业务空间、限流/额度、网络；以实际错误code为准，不仅凭403断言欠费 |
| 语音无声或变声 | 看实际音源/错误，检查系统输出与音量；关闭备用可保持原声；首次设备初始化可能较久；不要只看“播放中” |
| 麦克风不识别 | 检查Windows麦克风权限和中文识别引擎；仅开始语音后才聆听，静音/结束状态不会收音 |
| 动画不动/不合预期 | 检查动画、随机、手动预览、专注阶段和恢复自动；隐藏状态本来就不更新帧；原资源不要替换 |
| Q无效 | 默认需桌面空白处双击Q，不是在编辑器敲Q；组合键冲突则换键或用托盘 |
| 识屏失败/内容不对 | 确认授权和正确目标，先点目标；装OCR语言；目标勿最小化；受保护窗口/混合DPI需人工确认 |
| 监测数值不可用 | GPU/温度依API和驱动，CPU温度本就未提供；CPU首个采样需要建立差分基线 |
| 提醒没有立即弹出 | 检查勿扰、专注、锁屏、已有气泡、隐藏与过期；预约仍遵守保护规则；退出无法通知 |
| 程序无法启动 | 解压完整包，保留DLL和plugins；查看实际数据目录logs，确认没有同数据目录旧实例 |
| 数据无法保存 | 检查磁盘空间、目录写权限和独占实例；先备份，勿反复清空；恢复前退出程序 |
| 文件操作中断 | 看逐项日志；失败会尝试回滚；文件变更/原位置占用需人工核对，避免盲目重跑 |
