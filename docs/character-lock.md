# 固定角色外观

最新九宫格是角色形态依据。旧的高挑成年立绘已从当前程序资源中移除。
当前原画为 assets/shuangling-chibi.png，角色 ID 为 shuangling-chibi-v1，SHA-256 为：

9d14775e3be89a59dbe93a005e4b261ba5ca093052a5ef437cf3ef5338d36045

固定特征：圆润大头、短身比例、白发、紫瞳、白色龙角、白紫服装、龙翼和龙尾。聊天模型只生成文字，不生成或替换角色图片。
全身使用完整原画；半身使用同一原画的固定裁切。缩放保持原始比例，互动不自动切换镜头，不切成年形态、不换衣、不修改骨架。

v1.4 保留原主图作待机，增加 assets/actions-v2.png 中六组同角色动作（原图参考的 ImageGen 编辑素材）。动作之间使用平滑混合，主图不覆盖。允许局部眼睑、腮红、嘴型覆盖、整体轻微平移/倾斜和预制姿态。身体网格变形不启用。
当前实现是原生 2D 局部动画，尚未制作分层 PSD 或 Cubism 模型。未来若增加绑定模型，也须保持这组固定比例与服装。

assets/character.json 保存原画哈希与外观约束，assets/character-prompt.txt 保存 ImageGen 制作提示词。运行时不调用绘图服务。
GUI 冒烟验证校验原主图哈希和角色 ID，并在关闭动作时比较八种情绪的下半身像素。启用动作时允许预制肢体姿态变化，仍保持 Q 版身份与服装。新增六个动作会逐一渲染验证。


v1.7.0 在原画与既有姿态上增加尾巴、发丝和举手区域的局部动态；采用根部渐变的位移，仅作用于这些部件，头部中央、躯干与腿部保持固定。没有生成或覆盖角色 PNG，也没有改变服装、脸型和身体比例。关闭动画时保留原静态像素校验。
