# DragonGPT 1.6.0：主动对话、长期记忆、情绪与关系成长

本轮依据「桌宠功能设计」最后一条可读取的用户要求，把这四项作为一个可运行的功能组实现。入口为陪伴空间新增的「陪伴」页。

## 使用

- 主动对话：默认开启；未与桌宠互动 15 分钟后择机开场，两次至少相隔 90 分钟，每天最多 3 次。默认 22:00–08:00 免打扰，时间采用 Windows 本地时区。可调整或关闭，也可点「今天安静陪我」。
- 主动开场参考已确认的偏好、话题、称呼、关系阶段和仍有效的关心情绪，显示在气泡和历史记录中，来源标明「主动开场 · 本地」。未接话时不继续追问；重启不会清掉冷却、次数或等待状态。
- 自动开场采用有限的本地规则，不调用聊天或语音 API，也不自动朗读。接话后进入现有 DeepSeek／离线聊天流程。预览不写聊天、不消耗主动次数、不增加成长。
- 生成回复、输入框有文字或正在输入、语音忙碌、点击互动、全屏应用、模态弹窗和角色隐藏时，自动开场暂缓。全屏检测只检查前台窗口边界，不读取其他应用的文本或屏幕图像。
- 长期记忆：现有「记住：…」和记忆页手工保存继续可用，会补充资料、交流偏好或话题标签。明确的短句如「我喜欢十九世纪西方文学」可产生待确认建议；建议只在本地等待，不进入模型背景。点「确认保存」后才进入长期记忆，可再编辑、导出或删除；忽略后同一内容不再反复建议。此功能可关闭。
- 建议提取只覆盖少量明确的第一人称偏好、职业、生日和学习／开发近况，不进行后台模型摘要。问句、假设、明确拒绝记忆以及常见密钥或证件字段不生成建议。仍可手动保存其他内容。
- 情绪：用户表达困倦、喜悦、害羞或压力时，保存对应的陪伴表达状态；关心持续至多 45 分钟，其他至多 20 分钟，随后回到平静。短时思考表情结束后恢复仍有效的状态；重启会恢复未过期的状态。状态由本地关键词规则产生，不是诊断或对用户的评价。
- 关系：不同的真实用户交流每次 +2，每天最多 +20；同一天重复同一内容不重复加分。主动开场、预览、仅启动应用均不加分。互动天数只按有交流的日期累计，不按日历跨度累计，不因离开扣分。

## 阶段

| 阶段 | 成长要求 | 已记录互动天数 |
| --- | ---: | ---: |
| 初见 | 0 | 0 |
| 熟悉 | 60 | 3 |
| 默契 | 200 | 10 |
| 相伴 | 600 | 30 |

两个条件需同时达到。旧版已达到的「熟悉／默契」阶段作为最低阶段保留，折算为相应成长起点，不编造旧互动日期；新增互动天数从升级后的实际交流开始记录。清空本地数据会一并删除成长、情绪、候选记忆和主动状态。

## 数据与兼容

SQLite 版本由 3 升至 4，新增 `companion_life` 和 `memory_suggestions`，保留原档案、记忆、聊天和 API 用量。陪伴设置保存在同一数据目录的 `companionship.ini`。原有音色、语音开关、API 凭据、代理和 Q 版角色素材保持原配置。

主动对话与正常聊天使用不同信号，避免触发已有的打字朗读链路。真实来源会进入聊天历史；不会伪造用户发言、成功的云端请求或新的云端权限。

## 验证

新增 `dragon_life` 测试覆盖每日成长上限、重复内容、跨日门槛、时钟回拨、长期离开、免打扰、冷却、次数、未回复不追问、确认／忽略、敏感内容排除、跨重启恢复、情绪衰减、数据清除和旧版迁移。现有 GUI 套件增加陪伴设置、暂停／恢复、无声预览、确认／忽略的实际控件验证。GUI 冒烟增加陪伴页截图，并沿用原有角色身份与身体像素检查。

最终运行结果、发布哈希和数据保护结果见本次交付的 `验收结果.md`。测试使用本地 HTTP／SSE 模拟服务和本机语音能力，没有调用真实聊天或付费语音 API。
