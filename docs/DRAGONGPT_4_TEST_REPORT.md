- 本地DeepSeek原生协议夹具真的发出 tool_calls，工具读取真实磁盘字节，后续请求必须携带对应 tool_call_id 和实际结果，才返回夹具最终文本。验证了忙碌状态和最终聊天持久化。该测试证明调用链实现，不能冒充真实DeepSeek推理已验收。
- file_write 在批准前未创建文件；暂停后批准仍不执行，继续才落盘；取消后旧批准不能写入。队列拒绝重复，取消清空队列。旧工具异步结果绑定任务代次与调用ID。
- 参数拒绝未知字段、伪造approved、无效布尔/小数整型、未注册工具、未知开发动作。目录穿越、UNC、ADS、Windows设备名、尾点/空格、联接、私网与元数据IP受拦截。扫描不进入未授权子目录，工具宿主/ready文件不能通过模型文件工具访问。
- 在真实临时目录运行了 CMake configure/build/CTest；读取退出码和输出，未模拟编译。取消测试启动真实子进程并确认父工具被终止后子进程退出。最初清理遇到被杀进程尚未关闭文件句柄，修复为有上限的状态等待，保留原错误日志，没有删除取消断言。
- 写入使用哈希前提、备份与同目录临时文件；复制/移动核验哈希并拒绝覆盖。Word/Excel/PDF提取读取了真实生成的测试文件。
- 注入防护：网页/文件内容标记不可信，系统指令明确不能改变权限；高风险/网络请求始终需要具体操作批准，内容不能制造审批。测试中的恶意指令没有产生执行授权。这不是对任何模型提示注入的绝对免疫证明，用户仍须审核具体目标。
- 浏览器使用独立Edge上下文，不读个人profile/Cookie。精确角色定位、填入、文件上传、真实下载字节和密码拒绝均测试。网络搜索请求实际成功，但出现过搜索页内容与查询不相关，因此只能计为“请求成功”，不计为搜索质量验收。
- 桌面测试发现原生WinForms密码框可被UIA报告为Pane，IsPassword单独判断不充分。已增加原生Edit密码样式/密码字符元数据与子树排除；不读取密码值。测试控件密码不再返回，并且不能填写。无管理员/UAC窗口操作测试，不应宣称提权自动化通过。

## 语音评估

引擎基线：Windows中文SAPI。可选引擎：faster-whisper 1.2.1、CTranslate2 4.8.4，multilingual base，本机现成模型约145MB。未改默认TTS或强制将ASR切到本地模型。

生成10条可复现的本地SAPI合成音频，覆盖普通中文、加速音频、带停顿句、混合术语、项目词、加噪、低音量、连续指令措辞及TTS相邻措辞等类别标签。标签不等于真实环境：TTS相邻条目没有物理扬声器回灌，连续指令也不是完整真人连续会话。参考稿为合成输入文本。测试文件和清单在 work/asr-corpus，评估器在 asr/benchmark.py。

| 指标 | 实测 |
| --- | --- |
| SAPI合成集CER | 33.99% |
| 本地base CPU合成集CER | 23.53% |
| CPU推理中位数 / 最大值 | 812ms / 860ms，10条样本 |
| 模型加载 | 本轮781ms；不是冷开机最坏时间 |
| VAD+识别进程重放 | 实际返回中英混合最终文本，进程总耗时约1.875秒，其中推理796ms |
| CUDA实际讲话重放 | 缺cublas64_12.dll，明确CPU回退后成功返回文本 |

CER仅做大小写/空白/标点规范化，没有把繁体转简体；本地模型的部分繁体输出会算作字错误。普通中文样本中SAPI优于base，因此不能用总体数字证明每个场景都改善，更不能将该合成集外推到真人。空格分词WER只适用于有词边界的样本，不作为中文主要评价指标。基于现有证据保留SAPI默认，并提供本地CPU选择。

以下指标未计算，不能填入虚构数值：真人CER/WER、句首漏字率、错误截断率、意图准确率、真实TTS回声误触发次数、全程GPU峰值显存。没有用户标注的真人录音，也没有物理回声录音。有限流程测试中，临时识别、失败识别和无待确认最终稿均不会向Agent提交任务；这不是现场误触发率统计。

VAD确定性测试验证：静音不触发、分块帧拼接、前置缓存、450ms自然停顿不中断、可配置结束时间及30秒上限。重放测试实际使用WebRTC VAD；合成标签测试单独验证状态机边界。音频不作为运行日志落盘，测试音频仅位于显式测试目录。

## 性能

在无其他本次GUI测试并行的复测中，比较同一4.0桌宠的空闲与CPU-ASR并行负载。每种状态18个尺寸/半身/动作组合，每组30次同步 QWidget::grab。结果是离屏抓帧耗时，不是桌面合成器FPS：

- 场景平均耗时的中位数：空闲7.82ms，ASR并行8.48ms。
- CPU-ASR连续重放29次，推理中位数781ms，2个CPU线程。
- 实际ASR Python进程峰值工作集约316.3MB；含加载和约22秒循环的累计CPU时间47.0秒。采集运行模型的进程自身，未把Windows虚拟环境启动器的小工作集误算为模型内存。
- CPU压力后一次 nvidia-smi 读数：RTX5060 Laptop，8151MiB总显存，0MiB已用。此为结束时快照，不是全程峰值；CUDA兼容仍失败。

原始文件：work/performance-summary.json、performance-idle.json、performance-with-asr.json。没有宣称原渲染器性能被重构提升，也没有把本地夹具延迟当作云端TTFA。
