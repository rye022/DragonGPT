## 定位与修复

- 本地较旧源码落后于远程2.0.1：逐文件合入剪贴板和性能修复，避免回退。
- 原活动窗口不能被后台程序强制恢复前台：采用可终止的原生PrintWindow helper，只有确认目标在前台才允许屏幕像素回退。
- Windows stdout文本模式会破坏PNG二进制：helper显式使用二进制管道。
- 隐藏后动画帧仍执行：hide/show停止和恢复同一计时器。
- 主动决策未使用已有冷却/每日上限：落实配额并对忽略反馈退避。
- 连接保存重新构造设置可能丢失新/旧附加字段：从现有配置复制后更新。
- 工具取消/超时后迟到结果：代际标识阻止继续步骤，模态审核返回后复核执行状态。
- 新增智能页导致旧页数量断言不符：更新页面契约，保留原索引、按钮和功能断言。
- 旧音频测试冷启动预算短于本机实际枚举：独立探针量化后调整完成条件，保留播放断言。
