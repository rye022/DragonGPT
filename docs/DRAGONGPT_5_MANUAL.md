# DragonGPT 5.0 完整使用手册


本手册对应 GitHub v5.0.0。安装包和便携版见 [下载页](https://github.com/rye022/DragonGPT/releases/tag/v5.0.0)，动图和快速上手见 [README](../README.md)。

## 安装与升级

Windows 10 1809 / Windows 11 x64。安装器默认安装到 `%LOCALAPPDATA%\Programs\DragonGPT`，无需管理员权限；桌面快捷方式和开机启动可选。便携版完整解压后运行 `DragonGPT.exe` 或 `Start-Desktop.cmd`。安装器尚未进行代码签名。

升级前退出旧版，复制整个用户数据目录作为备份，包含数据库、配置和 DPAPI 凭据。已有便携版存档不会自动搬到新安装目录；可以继续使用原目录，或用 `--data-dir "原数据目录"` 指定。DPAPI 凭据与 Windows 用户绑定，跨用户或重装系统后可能需要重新输入。

默认用户数据为 `%LOCALAPPDATA%\DragonGPT\UserData`。5.0 迁移至 schema 8 并自动创建升级前数据库备份，旧版拒绝直接打开新数据库。回退需要退出程序、使用相应旧版和升级前备份。卸载保留用户数据。

## 5.0 养成中心

窗口最右侧「养成中心」及顶部入口可打开成长设置。有效交流、合格专注、待办完成和成功 Agent 任务贡献成长，单击有每日次数限制；每日共享 20 XP。亲密度满值后每天最多 10 次有效非单击互动可继续影响性格、信任和时段偏好。

活泼、傲娇、好奇、关怀、主动、幽默六个维度支持初始值与锁定。每次有限变化最多 0.1、累计偏移最多 ±10，可重置偏移并保存设置。信任从有效互动累积，旧存档不补造历史。关闭养成保留既有进度。

共同经历需要填写事实后明确确认，支持更正、删除和导出，不把模型推测直接保存为经历。自主建议、时段学习、成长待机、经历和探索均有独立开关。探索先准备目标，再到 Agent 审阅执行；只读工具范围受执行层限制，外部网页访问仍需批准。

详细规则、截图、导出和恢复见 [5.0 养成系统指南](DRAGONGPT_5_GUIDE.md)。

## 启动与数据

解压完整 Windows 运行包后启动 DragonGPT.exe；`--desktop` 只显示桌宠。原便携目录中若已有 `data/memory.sqlite`，继续使用原目录；否则使用 Windows 本地应用数据目录 DragonGPT/UserData。可用 `--data-dir <目录>` 指定隔离数据。不要把个人数据、INI、DPAPI 文件或模型权重提交到 Git。

升级保留原白发 Q 版龙娘、全部动作和口型、情绪、亲密度、长期记忆、主动对话、现有 TTS 音色与代理配置。当前渲染实际是 Qt 原生 sprite/mesh；没有随包绑定的 Cubism Live2D 模型，不能把原生动作称为已接入 Cubism。

## 对话、记忆与陪伴

- 对话：在连接页配置 DeepSeek 和代理。普通聊天保留原有本地小脑、在线/离线路由；断网显示实际失败原因。记忆指令仍在本地处理。
- 记忆：查看、搜索、编辑、删除和导出已确认的记忆；「记住：…」「叫我…」沿用原接口。建议记忆需要原有确认。Agent 工具内容不会自动写入长期记忆；最终任务对话保存在聊天记录中。
- 陪伴：原有情绪、亲密度、关系成长、静默时间、主动频率、勿扰与专注保护继续有效；主动台词不能启动 Agent。忙于任务时暂停主动打扰。
- 羁绊图鉴：解锁和收听状态仍分开记录，试听继续使用所选音色。
- 桌宠：单击当前动作播放相应台词，双击打开对话；Q 仅在桌面空白处双击切换显示，组合键选项在智能页。原有全身/半身、大小、隐藏和动作控制不变。

## 原有实用功能

- 工具页：待办编辑、优先级、时间提醒、每日统计、健康监测、文件整理。
- 专注陪伴：番茄钟、暂停/继续、专注统计、喝水提醒和延后/今天关闭。喝水朗读继续独立于专注朗读开关。
- 剪贴板：原有悬浮入口、历史与复制功能；是否记录沿用原授权。发送剪贴板内容继续由用户选择并确认。
- 智能页：原有按需截图、本地 OCR、模型分析、敏感窗口保护和静态工具计划。默认聊天仍能产生待审核计划，不直接执行。
- 文件整理：复用现有 FileOrganizer 扫描、逐文件目的地预览、哈希校验、移动日志和撤销。没有重复的后台整理器。
- 健康、日程、每日总结等被动功能沿用原有采样器与定时器，新增 Agent 不额外轮询。

## Agent 模式与授权

Agent 页提供三个模式，每次重启默认回到 A，目录授权只在当前会话生效。

| 模式 | 能力 |
| --- | --- |
| A 普通聊天 | 不进入自动工具循环；原有工具计划继续先预览 |
| B Agent 自动 | 在所选目录读文件、搜索、分析；有风险的动作仍逐项确认 |
| C 高级开发 | 额外允许审批后写代码、替换内容及运行固定开发预设 |

先选择授权目录，再输入任务。只允许本目录内部访问；拒绝目录穿越、UNC、符号链接/联接、系统目录、凭据和数据库等敏感文件。根目录授权不递归赋予其他盘符权限。网络请求、读屏、剪贴板、浏览器/桌面操作会展示具体请求或进入原有确认界面。网页和工具输出只能作为数据，不能产生授权。

任务使用 DeepSeek 原生 Chat Completions tool_calls，在实际工具结果后继续推理，最多 32 步、24 轮、10 分钟。一个任务执行，最多另排队三个不同目标；重复目标不加入队列。多工具调用串行执行，避免文件和音频竞争。点击「暂停」在当前工具完成后暂停后续动作；「停止任务」终止当前请求与工具进程树；「撤销授权」同时清空队列并回到 A。已完成的磁盘/外部操作不会因取消而自动回滚。

操作预览包含工具名称、全部参数、写入内容和目标路径。批准仅对这一次请求有效，模型参数中的 approved 等额外字段不被接受。审核时检查覆盖内容、上传对象、发送/发布按钮和开发命令。

最终回复是模型基于执行证据给出的总结；请结合任务日志、退出码、哈希和外部页面反馈核对。失败不会生成模拟成功结果。执行审计保存在数据目录 `agent-audit.jsonl`，最多约 1MB 一份并轮换，记录工具、步骤、时间和成功状态，不记录文件正文或凭据。

## 文件与文档

支持文本/源码分块读取、元数据、SHA256、按扩展名或时间列目录、文件名/字面内容搜索、PDF/DOCX/XLSX 提取、创建、复制、移动/重命名、整段写入、精确搜索替换和回收站删除。旧 DOC/XLS、扫描 PDF OCR、任意复杂 Office 排版不在当前文件提取器范围。

单次列表最多 200 项，递归检查最多 5000 项/5 秒；目录结构常见构建缓存被跳过。文本每次最多 24KB，可通过 offset/limit 继续读取，offset 为字节偏移，跨 UTF-8 字符可能产生替换字符。文档上限 16MB，PDF 最多前 20 页、工作簿有行列限制；返回结果明确标注局部内容。

覆盖和替换需要现有文件的 SHA256。覆盖前在源文件旁生成 `.dragon-backup-<时间>` 备份；复制和移动拒绝覆盖已存在的目的文件。移动返回反向路径，必要时审批反向移动恢复。删除仅处理单个已有文件，需当前哈希与批准，使用 Windows 回收站，由系统回收站恢复。

示例：「列出此目录最近修改的 Markdown 文件」「读取 src/main.cpp 并解释入口」「把这段配置替换为指定内容，先给我看完整参数」「预览下载目录如何按类型整理」。批量分类沿用工具页的现有整理预览。

## 网络与浏览器

网页工具实际请求公共 HTTP(S)、Bing 搜索和 GitHub 最新 Release，显示 source 与获取时间。拒绝本地/私网和带凭据的 URL；重定向逐跳校验。网页抓取固定连接到验证过的 IP，并保留 TLS 主机校验。本机 TUN 合成 DNS 场景会用 Google 公共 DoH 复核域名，这会向该 DNS 服务发送查询域名。没有浏览器用户 Cookie 或账号资料被复用。

搜索服务可能返回无关结果、反爬页面或验证码。成功获取搜索页只证明发生了请求，不代表结果相关或信息真实。技术问题应继续打开官方文档核对，最终引用实际来源网址。

浏览器使用独立的 Edge / Playwright 会话，支持 DOM 文本/角色、精确角色和可访问名称定位、点击、填入、滚动、切换页签、标记文件控件的上传及批准后下载。匹配不唯一就失败，不能按猜测点选。密码控件及凭据输入被拒绝。登录由用户手动完成；发送、发布、购买等任何点击都需要审核，必要时直接拒绝该操作。下载不自动运行文件。

示例：「打开 Qt 官方文档，查找 QAudioSource 的说明」「查看某 GitHub 仓库最新 Release」「在这个表单填入我明确给出的公开内容，提交前让我审核」。

## 桌面和开发工具

Windows UI Automation 可读取前台窗口和控件标签，按 AutomationId 调用、填入、切换窗口，或在当前控件实际边界内点击。控件必须唯一；窗口变化时重新读取。有限按键为 Tab/Enter/Escape/方向键。拒绝管理员窗口、已识别的敏感窗口和密码控件；不读取 UIA ValuePattern 值。未知/不可访问界面会失败，不会声称已操作。

开发命令不是任意终端。仅有 configure/build/test/git_diff/git_status 五种预设，不接收自由命令字符串。CMake 使用工作区中的 `build-agent`，并行度 2；开发命令 90 秒超时，输出约 24KB，工具进程树由 Windows Job Object 管理并有约 2GB 内存上限。运行 CMake/测试会执行项目脚本：这是批准的用户权限进程，不是 OS 级文件系统沙箱，项目自身仍能访问用户账号允许的其他位置。不要批准不可信项目的构建/测试。不会自动提权或安装软件。

示例：「分析这个 C++ 项目的构建配置」「先读错误相关源码，再提出精确修改」「在我确认后运行构建，再根据真实退出码修复」。项目缺 Qt/编译器或构建超时时会报告实际错误。

## 语音识别与音色

语音页新增识别设置；这些设置与现有 TTS 音色/模型完全分开。默认保留中文 SAPI，避免凭非代表性测试强行更换引擎。选定 ASR、语言、麦克风、结束静音时长、VAD 严格度、热词与自动发送方式后保存。SAPI 使用系统默认麦克风和中文语言包；其他设备/语言需选择本地或云端路径。

本地引擎为 faster-whisper，默认 CPU int8、2 线程；云端为用户指定的 HTTPS multipart 转写接口，响应必须提供 JSON text 字段。两条路径使用 Qt 实际设备格式转成 16kHz 单声道 PCM16，再用 WebRTC VAD，约 300ms 前置缓存、可配置 600–3000ms 静音、30 秒单段上限。无需重复安装降噪器；当前没有声称实现全双工 AEC，采用半双工和约650ms尾部保护。

「开始语音」后等待状态显示监听再讲话。支持等待静音自动结束，也可点击「结束本段录音」。临时结果只显示，不触发对话或工具。SAPI 可以提供临时假设，本地/云端适配目前是分段最终识别，界面不伪造逐字流式文本。

最终稿在对话页显示原文和规范化文本，可编辑、确认发送或丢弃/重说。默认不自动发。自动发送仅用于没有不确定信号、术语修改和操作措辞的普通聊天；涉及真实操作还会经过 Agent 逐项权限检查。未收到稳定文本、超时、设备中断、过低音量、疑似幻觉或失败时不提交指令。不显示虚构置信度。

热词用逗号分隔，例如 `DragonGPT, Live2D, C++, Python`。引擎支持时使用词汇提示；授权工作区名称也会加入本次词汇。默认纠错只统一精确 ASCII 术语的大小写，不用大模型猜测中文同音词。可明确设置 `自定义别名=>术语`；发生替换必须核对，原文始终显示。不会把纠错结果声称为实际听到的字。

云端模式需要单独 ASR 密钥，通过 Windows DPAPI 保存；选择该模式表示允许把本段音频上传到你指定的服务，可能计费。当前版本未做真实云端计费验证。SAPI/本地模式不会上传音频。

## 准备可选依赖

已准备的本机工作副本通过不提交到 Git 的 ready.json 找到运行时和本地 base 模型。可搬运的源码/运行包不包含机器路径、模型权重或 Python 环境。在目标机器上手动执行：

```powershell
python agent/prepare.py --with-asr --model base
```

这会安装锁定版本的依赖并明确下载 base 模型；不需要本地模型时可省略 `--model base`。不需要 ASR 可省略 `--with-asr`。之后程序会从 agent/asr 的 ready.json 读取运行时，或在 UI 中填写 Python 和模型绝对路径。浏览器还需本机已安装 Edge。安装脚本不会由 Agent 自动调用。

RTX 5060 8GB 不等于所有 CUDA 运行库都齐全。此次实际 CUDA 推理因 cublas64_12.dll 缺失回退 CPU；不要据设备枚举成功认定 GPU 已通过。CPU 路径可运行；GPU 需要用户安装相互兼容的 CUDA12/cuDNN9/CTranslate2 后重新验证。

## 故障排查和人工验收

- 无识别：检查中文 SAPI 包、系统默认输入设备或所选 ASR Python；本地/云端还需 webrtcvad 依赖。原始错误会出现在状态区。
- 首字遗漏/断句：等待“监听中”，适当提高静音阈值；用人工标注录音对照。不要用合成样本的 CER 保证真实讲话效果。
- 一直准备：模型加载有120秒上限，确认模型目录已有 model.bin；不会自动下载。
- 工具失败：看任务日志和退出码，确认模式、目录、Python、依赖及当前窗口是否改变；取消后可重新提出任务。
- 网页异常：可能被服务端拦截；证书错误不能通过关闭 TLS 校验解决。确认系统信任链或安装 truststore。
- 无声音：检查原 TTS 设置、所选音色的实际错误与输出设备；新 ASR 不会静默替换原音色。
- 升级核对：先完整备份数据；检查 SQLite integrity、原有记录、配置哈希、快捷键、六组动作、口型、记忆、提醒和实际所选音色输出。

人工验收应使用授权的真人录音覆盖中文、快语速、停顿、混合语言、术语、项目词、噪声、低音量、连续指令和 TTS 相邻场景，标注原文后运行 `asr/benchmark.py`。观察实机麦克风音量、TTS 扬声器回声和录音首尾，并核实任何临时/失败结果都没有产生工具调用。没有这些样本时，不应宣布真实 CER/WER 或回声误触发率通过。
