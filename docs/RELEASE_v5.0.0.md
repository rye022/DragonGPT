# DragonGPT 5.0.0

5.0把原有记忆、情绪、亲密度、主动生活和Agent连接成可解释、可控制的成长闭环。新增养成中心、六维性格、信任、任务成长、共同经历、时段适配和带工具范围限制的只读探索。

角色资产、精灵动作、现有AI接口、TTS音色链路和原用户数据架构继续沿用。当前没有Cubism模型；不会把精灵动画描述成已绑定Live2D。

SQLite升级前自动备份，新增字段随schema 8事务迁移；旧版拒绝直接打开新库。每项成长和自主特性可以独立关闭。

本次 GitHub 发布提供 Windows x64 安装器、完整便携运行包、源码 ZIP 与 SHA256SUMS.txt。README 包含使用说明、完整手册入口和实际程序渲染的动作动图。

- 养成中心：六维性格、信任、任务成长、已确认共同经历、互动时段学习。
- 亲密度满值后的有限延续成长，以及有原因记录的主动决策。
- 基于 4.0 Agent 的受限只读探索，保留目录授权、逐项审批和取消。
- 沿用 4.0 文件/文档/网页/浏览器工具、独立 ASR/VAD 与可编辑识别稿。

安装版默认安装至 `%LOCALAPPDATA%\Programs\DragonGPT`，无需管理员权限；便携版完整解压运行 DragonGPT.exe。可选 Python 环境、ASR/TTS 模型和云端密钥需要自行配置。安装包未进行代码签名。

升级前请退出旧版并备份存档。默认存档为 `%LOCALAPPDATA%\DragonGPT\UserData`，已有便携目录的数据继续保留。schema 8 数据不能直接用旧版打开，需要回退时请使用升级前备份。

开发验证与性能详见 [测试报告](DRAGONGPT_5_TEST_REPORT.md)，本次安装器及附件验证见 [发布验证记录](RELEASE_v5.0.0_VALIDATION.md)。真实云计费、真人麦克风、新系统依赖与24小时运行尚未全面验收。
