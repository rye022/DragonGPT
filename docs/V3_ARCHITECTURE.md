# V3 架构、数据流与权限边界

基于原 Qt Widgets / C++20 / SQLite / MinGW。现有图像、台词、动作、语音、记忆、情绪、关系、专注、剪贴板、健康和文件整理继续负责各自领域；不建立重复记忆数据库或第二套监测/剪贴板监听。

| 组件 | 职责 | 生命周期/敏感数据 |
|---|---|---|
| ScreenCapture | 原活动句柄、窗口/显示器、隐私策略、按需捕获 | 每秒元数据观察，不后台截图；像素仅在本次内存流程 |
| ScreenOcr | 系统 WinRT OCR | 固定 PowerShell helper、标准输入、无临时图像、25秒截止 |
| ContextEngine | 标题/按需事实启发式分类 | 10秒滞后、低打扰情境优先；仅结构化类别共享 |
| ChatService | Responses、流式、取消/超时 | GUI线程内单生成并发闸门，不自动重发付费请求 |
| ToolHub | 注册/验证/顺序计划/状态机 | 最多8步、重复拒绝、代际标识拒绝迟到回调 |
| MemoryStore | 原 SQLite 记忆及关系 | schema 7、不平行建库、相反偏好需确认 |
| 原领域服务 | 健康/专注/待办/剪贴板/文件 | 复用原计时、线程和撤销日志 |

屏幕图像不加入 Companion::sendMessage，不经聊天保存或自动建议进入长期记忆。解析内容作为不可信数据；分析请求不绑定可执行工具。模型计划只在注册白名单中解析，不能新增 shell、覆盖、删除或系统设置能力。

## 权限和执行

健康、总结和待办列表为只读。写待办、启动专注、读屏、资料选择和剪贴板入口需审核计划。文件工具只扫描；移动仍在原页面逐文件确认并使用禁止覆盖、哈希和撤销日志。

取消/超时不会回滚已完成步骤。同一计划不能再次运行，重新规划创建新任务。幂等本地只读失败最多重试一次；非幂等写入与付费生成不重试。审计内存保留最近100条工具元数据，结果区显示实际反馈。

这是受控工具 Agent。常见目标用本地规则，复杂模型可提出白名单内的多工具计划；不支持通用 GUI 操作或任意文件管理。情境是启发式判断，窗口/密码检测有漏判及误判；不能代替用户授权。
