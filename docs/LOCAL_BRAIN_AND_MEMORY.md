# v2.0 使用与实现边界

## 本地小脑

LocalBrain 用整句规则、优先级、参数和冲突回退处理明确指令，复用原回复保存、情绪、关系、TTS、界面及动作通道。时间、星期、CPU/内存、动作、待办、番茄钟和喝水预约可本地执行；复杂消息继续走原 DeepSeek/离线流程。

例如：现在几点了、我的 CPU 占用率是多少、进入认真工作状态、开始45分钟番茄钟、暂停番茄钟、还有多久休息、明天下午三点提醒我复习高数、查看今天的待办、30分钟后提醒我喝水。

“我今天不想工作了”、假设、引语、否定与不明确的组合指令不会直接触发动作。疑似凭据在上传与保存前拦截；Key 仍从原连接/语音页使用 DPAPI 加密保存。

本地指令不调用聊天 API；如果开启朗读并选择云端音色，文字朗读仍会使用当前 TTS 服务，沿用原来的来源显示和计费方式。

## 语义记忆

SQLite 保存原记忆及 512 维向量、模型标识、内容指纹、来源、层次和更新时间。编辑立即失效，删除/过期/清空同步移除索引，后台结果返回时再次核对内容和指纹。短期历史保持原机制；长期语义、情景经历和关系经历可分层管理。亲密度、情绪、解锁和奖励继续由原结构化表决定。

模型为 [BAAI bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5) 的[固定 ONNX 转换版本](https://huggingface.co/onnx-community/bge-small-zh-v1.5-ONNX/tree/9507db33464b5da99a532ac26b2a251767cbc62b)。量化权重约 24 MB，CLS 池化，128 token 上限。独立 CPU 进程限制两个计算线程，闲置 60 秒释放，不加载本地聊天大模型、不占显存。

子进程关闭遥测，禁止网络 socket；只返回 ID、分数和指纹。新建/编辑后的索引在下一次检索时批量生成，一轮最多 256 条，查询最多读取 20,000 个向量。未索引内容仍有原文字检索。模型缺失、文件损坏、启动失败、数据库繁忙、推理错误或 15 秒超时均明确降级。长记忆会截断，重要事实宜分条保存；未做大规模中文准确率基准。

自动提取只整理明确一人称偏好、学习/工作计划和重要经历，确认后才保存和进入聊天，不额外调用提取 API。记忆页支持内容/标签/来源/层次筛选、编辑、删除、清空、自动建议开关、导入导出、更新时间和备份。

主动学习跟进默认关闭，保留旧隐私偏好。开启后继续遵守原主动调度和忙碌/勿扰保护；同一话题至少隔三天、一天最多一次，不在未回复、低落或专注时追问。仅使用多线程/C++/数学等有限学习标签，不朗读记忆原句；陌生话题宁可不提。可关闭单条主动引用，也识别“别再提多线程了”。

删除长期记忆不会抹去旧聊天中的原文；删除历史聊天需使用原档案清空入口。

## 待办与原专注服务

支持今天/明天/后天、中文小时/半点、24 小时制、完整日期时间和相对分钟/小时。“明天三点”这类歧义时间确认前不保存。支持优先级、完成/重新打开、删除、当天与逾期概览。

待办提醒跨重启保存，每项只提醒一次；聊天或语音繁忙时排队。退出期间不能弹提醒，重新运行后补查。番茄钟和喝水调用原 FocusService，保留阶段语音、休眠后暂停、勿扰、确认/延后和奖励。预约不改写用户的周期设置。

## 剪贴板

默认关闭监测，不读取已有系统剪贴板内容。可动画展开、重新复制、固定、删除和清空。优先位于角色下方，边缘使用不遮挡的位置；极小屏幕可能需要移动角色。最多 50 条普通与 20 条固定记录，普通记录默认 24 小时，可设 1–720 小时，固定记录由用户删除。

本地识别文字、代码、URL、路径和报错。密码、Key、长随机令牌、验证码、带查询/片段的 URL 等保守拒绝留存。检测有局限，复制私人内容前可关闭监测。清理历史不更改系统当前剪贴板。

AI 分析只有点击并确认后才发送选中条目，不自动预生成或上传其他历史；长内容需先复制不超过 1600 字的片段。

## 电脑健康与总结

每 5 秒后台采样 CPU、物理内存和可用 GPU 指标，最多保留 120 点趋势。GPU 使用 Windows 性能计数器，必要时用系统目录里的 NVIDIA 驱动接口；温度依驱动支持，CPU 温度缺失明确显示不支持。[NVML 官方接口](https://docs.nvidia.com/deploy/nvml-api/latest/api/group__nvmlDeviceQueries.html)。

CPU/内存 ≥90% 或 GPU ≥95% 持续两分钟才提示，至少隔 30 分钟；休眠等长采样间隔打断持续判断。不凭单次读数判断硬件故障，磁盘、网络等未测项目不作确定诊断。

每日总结使用运行期间观察到的近期键鼠活跃时间、原番茄钟统计、待办、负载事件、对话次数和待处理事项；不是全天全系统审计，不读取其他应用文字。可导出文本或主动保存一条情景记忆，云端文字回顾需要确认发送统计摘要。

## 文件整理

只扫描用户选择目录的直接子文件：图片、文档、压缩包、音视频。跳过隐藏文件、程序、未知类型、子目录和链接，拒绝系统/应用数据目录和重解析点。SHA-256 识别重复内容，保留全部副本。

扫描、哈希、移动和撤销在后台，可取消。先完整预览再确认，执行时重新核对文件和路径，同名避让、不覆盖、不删除。操作前后保存日志；中途失败尝试安全回退。撤销遇原路径占用或内容改变则停止，保留日志，不覆盖较新内容。断电后的外部改动不保证都能自动撤销。

## 安装与数据恢复

schema=7 迁移前创建 memory.sqlite.pre-v7-*.sqlite；事务与完整性检查通过后提交。备份包含数据库里的记忆、向量、关系、聊天、图鉴和工具记录；INI/DPAPI 在 data 中单独保留。安装脚本升级前另备份整个 data 和旧 EXE。

先退出对应实例，再运行：

```powershell
DragonGPT.exe --data-dir "现有 data 目录" --restore-backup "备份.sqlite" --verify-data
```

恢复先验证格式/完整性，另存当前库用于回退。本次开发不覆盖正在运行的旧安装。

本机 dist/DragonGPT 已准备语义环境。ZIP 不包含 Python 环境、机器路径、私人数据或凭据；换电脑需 Python 3.12 x64，执行 embedding/install.ps1 安装公开依赖/模型。未安装时结构化记忆和其他工具仍可用。正常使用不下载模型、不上传记忆用于 Embedding。

本轮未做真实付费 DeepSeek/百炼调用、真实云端延迟对比或主观音色验收；其他硬件、极小屏幕和大记忆库仍需额外验证。
