# DragonGPT V3.0.0 中文用户指南

DragonGPT 是 Windows 桌面伙伴「霜翎」。她保留原有 Q 版白龙娘立绘、六组动作、眨眼、抱尾、口型、台词、语音和关系成长。V3 在现有功能上加入按需屏幕识别、共享情境信息、任务计划与受控工具协作。

本文对应实际实现。软件可以规划并调用已注册工具；任意命令执行、无人监管的文件批量移动、持续观看屏幕和通用电脑操作并未开放。

## 安装、启动和卸载

系统要求：Windows 10 1809 或更新的 64 位 Windows；本地 OCR 需要 Windows OCR 语言包及系统 Windows PowerShell 5.1。普通聊天、桌宠、统计和待办不需要 Python 或 Node.js。可选的本地语音大模型、语义向量检索需要额外准备运行环境和模型；默认安装包不包含这些大型组件。

1. 从项目 Release 下载 `DragonGPT-Setup-v3.0.0-win-x64.exe`，用 `SHA256SUMS.txt` 校验。尚未正式发布时，使用本次交付目录中的本地安装器。
2. 运行安装器。默认安装到 `%LOCALAPPDATA%\Programs\DragonGPT`，无需管理员权限。开始菜单入口自动创建；桌面快捷方式和登录自启动可选，默认不勾选。
3. 从开始菜单启动。首次运行显示桌宠，双击桌宠进入陪伴空间。默认离线；没有密钥也可以使用本地功能。
4. 需要自启动时，在安装器的任务页选择 “Start DragonGPT when I sign in”，或者重新运行安装器修改该选项。已有旧版启动项不会被擅自删除，避免重复启动需要自行取消旧项。
5. 卸载使用 Windows「已安装的应用」或开始菜单的卸载入口。默认保留用户记忆、设置、缓存和旧版便携数据。

新安装默认数据目录为 `%LOCALAPPDATA%\DragonGPT\UserData`。如果程序目录已有 `data\memory.sqlite`，会优先继续使用该旧版便携数据。`--data-dir` 可显式指定数据目录。不要同时让两个进程写同一数据目录；程序使用锁和本机 IPC 限制重复实例。

升级前请退出原实例，备份整个旧版 `data` 目录。需要沿用旧数据时，将备份复制到新数据目录或通过 `--data-dir` 指定原目录。请保留原备份；DPAPI 密钥只能由原 Windows 用户解密。安装器不会自动猜测并迁移其他目录里的数据。

## 配置 DeepSeek

打开「连接」，输入你的 API Key、轻量模型 ID 和代理方式，再保存。Key 用当前 Windows 用户的 DPAPI 加密；不会写入源码或普通 INI。环境变量 `DEEPSEEK_API_KEY` 存在时优先使用。不要把 Key 发到聊天、剪贴板历史或记忆里。

「智能」页可另设复杂任务模型和视觉模型。复杂模型留空时沿用「连接」模型。普通聊天优先轻量模型或已有本地规则；规划、复杂屏幕推理可使用复杂模型。

选择「读取可用模型 / 测试认证」会请求官方 `/models`，显示可用 ID 与服务声明的图像能力，不发起文本生成。它验证认证和列表读取，不代表余额足够或实际生成一定成功。实际聊天和视觉分析可能产生 API 费用。

截至本次核对，官方 [视觉文档](https://api-docs.deepseek.com/guides/vision/) 明确支持 `deepseek-flash` 的图像输入；不能据此认为任意旗舰模型都接受图片。其他视觉 ID 需由 [模型列表](https://api-docs.deepseek.com/api/list-models/) 声明 `image`。服务变更后应重新核对。复杂推理使用 [Responses API](https://api-docs.deepseek.com/guides/responses_api/)，模型 ID 可配置。

常见错误：401 通常需要检查密钥；403 需要检查账户/模型权限或提供商限制；429 需要稍后再试；连接超时需要检查代理和网络。HTTP/SOCKS5 失败不会偷偷改成直连。生成失败显示原因并恢复消息草稿；不会自动重发付费请求。可随时点停止。

## 功能使用

### AI 聊天

双击桌宠，在「对话」输入并发送，例如「帮我理解 C++ 引用」。在线时发送本轮消息、有限的近期对话及相关已确认记忆；离线时使用诚实标注来源的本地规则。点停止可以取消生成并恢复草稿。模型不具备的实际电脑操作不会被当作已执行。

### 智能屏幕识别

1. 打开「智能」，勾选按需屏幕授权。默认关闭，不会后台循环截图。
2. 选择「上一个活动窗口」、具体窗口或显示器。显示器列表支持多个屏幕，窗口列表可以刷新。
3. 先点击要识别的软件，再从桌宠右键「识别原活动窗口」或 `Ctrl+Alt+S` 发起。无需先打开聊天窗口。快捷键被占用时会提示，可用桌宠或托盘入口。
4. 默认使用 Windows 本地 OCR，适合文字、代码、网页正文。在线开启时，将提取文本交给配置的推理模型；离线时只显示 OCR 原文。
5. 图形、复杂公式或布局适合选择「视觉模型 → 推理」。这会上传所选截图，先提取事实，再将文本交给复杂模型。视觉能力未经确认的模型会被拒绝。

截图时会临时隐藏 DragonGPT 窗口，并尝试恢复原目标到前台；捕获完恢复原窗口状态。如果无法恢复目标、安全桌面不可访问、目标最小化或权限不足，会明确失败，不会偷偷改读其他窗口。显示器捕获更保守：检测到敏感或不可验证窗口时要求改用窗口识别。

总开关、软件/标题关键词屏蔽、密码输入框与登录/支付/无痕标题检查共同生效。这些检测不能保证识别所有私人内容；私人操作前应关闭总开关。DRM、管理员窗口、受保护视频或某些全屏程序可能无法获取。多显示器和不同 DPI 的兼容性取决于 Windows/驱动，见本次测试报告。

截图不写磁盘，OCR 通过内存传入系统识别进程。屏幕事实、回答只临时显示，60 秒后清除；可以手动取消清除。相同截图、问题和模型设置可命中 30 秒内存缓存，避免重复生成。屏幕内容不会默认写入聊天、记忆、关系数据或操作审计。

使用示例：「解释屏幕上的编译错误」「总结当前文章」「读出题目并说明解题思路」。OCR 可能识别错字符；遇到公式请核对原图。

### 情境感知

在「智能」单独开启本地情境判断，且屏幕总开关必须开启。服务观察活动窗口标题，结合最多5分钟内的近期提问，并在用户发起 OCR/视觉分析后使用提取内容，输出编程、学习、阅读、排错、会议、全屏或未知情境及置信度。变化需稳定约 10 秒；会议/全屏保护立即生效。它不在后台截图或调用 AI。

情境分类共享给任务规划、聊天背景与主动交互保护；低置信度、全屏和会议会降低主动打扰。窗口标题不写入日志。情境只是本地启发式判断，不能准确识别每种游戏或会议软件。

### 任务计划和工具调度

在「智能」输入目标，点「制定计划」。例如「检查电脑为什么变卡，再总结今天的使用情况」。已知目标先用本地规则规划，其他目标在在线服务启用时可请求复杂模型。计划最多 8 步，只接受已注册工具及声明参数，拒绝重复步骤和未知工具。

先核对计划，再点「执行预览中的计划」。健康、每日总结、待办、番茄钟、文件预览、剪贴板和屏幕识别复用原服务。结果区展示工具和结果；审计只保留工具 ID、时间、步骤、成功状态和尝试次数，不保留输入、路径或内容。

示例：

- 「帮我整理下载文件夹里的学习资料」：选择目录，生成原有文件整理预览；不会直接移动。
- 「提醒我半小时后休息」：进入待办审核，核对标题和时间后保存。
- 「帮我整理刚复制的内容」：打开现有剪贴板助手，选择一条并确认发送。
- 「总结学习资料」：选择不超过 64 KB 的 UTF-8 文本文件，审核最多 12000 字片段后总结。暂不直接解析 PDF/Word。

工具按顺序执行，受超时和取消控制。幂等的本地只读步骤最多重试一次；写入和付费生成不自动重试。失败后停止剩余步骤；可以修正条件后重新制定计划。取消不会撤销已完成的写入。待办可在原工具页删除，文件移动可使用原日志撤销。

任意 shell 命令、删除文件、覆盖文件和修改系统设置没有注册为 AI 工具。文件整理的批量移动仍需在原页面核对每个目标并再次确认。仅生成预览或打开入口的步骤会明确报告需要的后续操作。

### 长期记忆

在「记忆」添加、搜索、编辑、导入/导出或删除记录，也可说「记住：我喜欢安静的回复」。明确记忆指令本地执行。自动提取只产生待确认建议；在「陪伴」确认后才进入原来的长期记忆表。可在「记忆」或「陪伴」关闭自动建议。

规范化后相同的记忆复用原 ID；相反的「我喜欢/我不喜欢」偏好会要求确认替换。复杂的语义冲突仍应手动编辑，不会由模型擅自覆盖。旧记忆在关键词检索中逐渐降权；过期行为和本地语义检索沿用原系统。每次只取有限相关记忆，不把整库发给模型。资料/交流偏好标签有明确的数量上限。

敏感信息不默认生成自动建议。显式保存也会拦截疑似凭据。自动台词不引用私人记忆。编辑或删除记忆不会清零亲密度、聊天、情绪或隐藏台词。

### 主动对话、关系成长和动作

在「陪伴」调整主动性、冷却、每日上限、安静时段和勿扰。默认本地筛选和选台词，云端音色朗读仍可能调用 TTS。正在聊天、语音、专注、输入、全屏保护或桌宠隐藏时会暂缓。连续忽略开场会延长冷却，达到每日上限停止当日主动开场，不积压补播。

真实聊天、点击和已完成专注按原规则增长关系；自动开场和试听不会刷亲密度。羁绊图鉴保留解锁、收藏和听过状态。点击按当前动作轮换专属台词；双击聊天；右键选择招手、抱尾、休息、工作等原动作。随机轮换、半身镜头和缩放仍在原设置中。V3 没有重绘原素材。

### 剪贴板助手

桌宠头顶入口展开剪贴板面板；记录默认关闭。启用后记录安全文本并保留缩进、换行和 Unicode。双击条目或点复制后可粘贴，支持固定、删除和保留时长。复制时有原生读回校验和短暂占用重试。关闭记录不会删除已有条目；私人内容前应关闭。AI 分析每次需选中内容并确认发送。

### 番茄钟与喝水提醒

在「专注陪伴」设置任务、工作/休息长度及喝水选项，支持开始、暂停、继续、结束和本地统计。例如「开始25分钟番茄钟」「30分钟后提醒我喝水」。锁屏、离开及 API 不可用状态会按已有保守规则处理；不记录键盘内容或网站。

喝水提醒支持「我喝过啦」「15分钟后提醒」「今天不再提醒」。它是陪伴提醒，不推断实际饮水量或身体状况。程序退出时无法发出提醒，重新启动恢复已有状态。

### 电脑监测、健康和每日总结

「工具 → 电脑健康」复用一个后台监测器，约每 5 秒采样，趋势最多 10 分钟。CPU、内存、GPU 等以实际 API 可用性为准；温度等不可用时诚实提示。持续高负载才触发提醒，不凭瞬时占用率断言故障。

「工具 → 每日总结」显示桌宠运行期间记录的活跃、专注、待办及互动统计。刷新、导出和手动保存情景记忆均保留。请 DeepSeek 回顾前会展示发送确认。未运行时段和其他应用内容不会被补造。

### 待办与文件整理

「工具 → 待办」可新建、完成、重新打开和删除。自然语言解析有歧义时需核对提醒时间；关闭程序期间不能实时通知，重新运行后补查逾期任务。

「工具 → 文件整理」选择个人目录，先扫描，核对每个原路径/目标，再确认移动。沿用不递归、不删除、不覆盖的分类规则；内容重复的文件仍保留。执行可取消，已完成部分写入撤销日志。撤销时文件已改变或原位置被占用会停止，不覆盖任何内容。下载目录中的程序或系统目录不应交由通用整理规则处理。

### 快捷键与托盘

默认 Q 是“桌面空白处双击 Q”，仅 Explorer 桌面获得焦点时触发。文本框、代码编辑器、游戏内的普通 Q 不会触发或被吞掉。在「智能」可改为 `Ctrl+Q`、`Alt+Q`、`Ctrl+Alt+Q` 或关闭；组合键使用 Windows 注册并报告冲突。

`Ctrl+Alt+S` 触发已授权的屏幕识别，冲突时可使用桌宠/托盘入口。隐藏只暂停桌宠动画，保留位置、聊天、关系和内存资源，必要的提醒与快捷键继续运行。托盘提供显示、隐藏、聊天、设置、屏幕识别和退出。系统没有可用托盘时应保留可用窗口或使用组合键恢复。

### 语音

「语音」选择原有系统中文、本机模型或百炼音色，配置各自入口、地域、模型和加密凭据。试听、点击台词和聊天朗读沿用当前选择，来源和失败原因会显示。需要备用音色时由用户开关控制，不伪装成原音色。

打字朗读不会开启麦克风；只有开始语音才尝试听音。声卡、中文识别引擎、离线模型和云端权限决定可用性。关闭朗读仍可文字聊天。未进行真实云端合成时，不把协议测试当作主观音质或可听输出验证。

## 故障排查

| 问题 | 处理 |
|---|---|
| 无法启动 | 用完整安装器或完整 ZIP，检查是否缺 DLL；不要只复制 EXE；查看数据目录 logs |
| 已有旧实例 | 从原托盘退出；确认快捷方式目标和数据目录，避免两个安装分别使用不同数据 |
| AI 无法连接 | 核对 Key、模型 ID、代理、账户权限，先读模型列表，再手动发送小问题 |
| OCR 不可用 | 安装 Windows 对应 OCR 语言；检查 PowerShell 能否启动；可配置已确认支持图片的模型 |
| 屏幕目标错误 | 先点击目标软件，再用屏幕快捷键；刷新窗口列表；确保目标未最小化 |
| 敏感窗口被拦截 | 关闭私人窗口后重试；不要通过关闭系统安全保护绕过 |
| 语音无声 | 看实际来源/错误、系统输出设备和音量；核对云端地域/音色权限；不要仅凭“播放中”判断有声 |
| 动作异常 | 在设置恢复自动动作、检查动画开关和图集；原角色文件请勿替换 |
| 快捷键失效 | 单 Q 只在桌面双击有效；换组合键并查看冲突提示；托盘可恢复 |
| CPU/内存高 | 先看健康页，关闭不需要的可选本机大模型；隐藏桌宠可停止帧定时器；记录版本与日志排查 |
| 任务中断 | 查看已完成工具和失败步骤；重新制定计划；不要盲目重复可能已完成的写入 |

## 隐私、备份与删除数据

本地保存聊天、已确认记忆、关系、情绪、收藏、待办、专注统计、设置和按用户开关记录的剪贴板。密钥由 DPAPI 加密。必要的诊断日志会记录状态和耗时，不应包含屏幕正文、完整工具参数或 API Key。

在线聊天会发送本轮消息、有限近期对话和相关记忆；屏幕 OCR 推理发送提取文本，视觉模式还会发送本次截图；用户确认的剪贴板/资料分析发送选择的内容；云端 TTS 发送待朗读文本。这些由相应服务商处理。离线模式不会因此具备云端能力。

关闭屏幕总开关会取消当前屏幕分析并清除临时结果；不影响既有聊天和记忆。关闭自动记忆只停止建议生成，已有记忆仍可编辑删除。卸载不会默认删除用户数据。需要彻底清理时，先退出所有实例并备份，再自行删除实际使用的数据目录；这也会移除设置、关系、收藏、缓存和加密凭据，无法通过软件恢复。

本次真实测试范围、未通过项目、硬件/云端限制及是否正式发布，以交付的测试报告和 Release 状态为准。
