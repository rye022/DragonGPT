# DragonGPT 4.0.0 版本说明

基于真实 3.0 审查修复源码增量实现，没有更换角色资产、动画渲染器或 TTS 音色，也没有重建现有待办、专注、剪贴板、健康监测和文件整理器。

- Agent：DeepSeek 原生 Chat Completions tool_calls → 参数验证 → 权限/逐项预览 → 异步执行 → 工具结果回传 → 后续推理。最多32步、24轮、10分钟；单任务执行、最多3项等待队列；暂停、取消、授权撤销、进程树终止与无正文审计。
- 文件：工作区内真实读写、元数据/哈希、分块、名称/内容搜索、文档提取、复制/移动、精确替换、覆盖备份和回收站。原文件整理预览与撤销继续复用。
- 网络/浏览器：真实公共网页、搜索与 Release；独立 Edge 会话、DOM/角色定位、表单、页签、上传/下载；浏览器不复用用户 Cookie，密码控件拒绝访问。
- 电脑/代码：Windows UI Automation、前台窗口校验、控件调用/填入/边界点击、受限按键；开发模式只运行固定 CMake/CTest/Git 预设，保存实际输出与退出码。
- 语音：独立 SpeechRecognitionService；SAPI 多段聚合、假设/最终分离、释放设备与超时；可选本地 faster-whisper / 云端兼容转写。PCM转换、WebRTC VAD、前置缓存、静音阈值、30秒上限、手动结束与半双工尾部隔离。
- 语音可靠性：热词/项目词、明确别名、保留原文、术语大小写规范化、最终稿编辑与丢弃。临时/失败结果不触发任务，不伪造置信度；操作指令继续经过同一 Agent 权限层。
- 版本：应用、资源、安装脚本、安装器和打包元数据统一4.0.0。

仍需区分实现与验收：当前本机 CUDA 实际推理缺 cublas64_12.dll，CPU 回退已验证；未安装 CUDA 系统组件。没有真人录音或云端 ASR 计费测试，不能宣称这些已经完成。合成音频结果只适用于测试集。没有全双工AEC、任意Shell、管理员自动化或OS级代码沙箱。浏览器反爬/验证码、旧Office格式和扫描PDF需额外处理。完整细节见测试报告。

升级前备份完整用户数据、配置和旧程序。现有 schema 7 保持兼容，新增 Agent/ASR 使用独立配置与无正文审计。不得覆盖 GitHub 已有正式 Release；本次交付为本地构建。
