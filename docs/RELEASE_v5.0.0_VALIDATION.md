## 范围与限制

安装和卸载在本机的隔离目录进行，不能替代全新 Windows 系统验收。没有修改当前正在使用的桌宠程序、用户数据、凭据、音色或快捷方式。云端付费模型与真实语音授权、真人麦克风、多屏/DPI、全屏游戏/真实会议及 24 小时以上运行未在本次发布中完成全面验证。

安装器未进行代码签名。项目源码公开供查看，项目自身代码和角色资产尚未授予开源许可；第三方组件遵循各自许可。
