# 霜翎 v1.11 情绪说明

## 本次修复

原系统虽然定义了思考、好奇等状态，持久心情却忽略了它们，回复结束后又用旧心情覆盖结果。待机循环独立随机选择全部动作，番茄钟只控制姿态，台词与语音读取的状态也不完全一致。

现在沿用原有 EmotionEngine、LifeState、ActionCycle 和语音管线，统一解析当前情绪。旧情绪编号保持不变，新状态追加；不改变数据库表结构、成长门槛、奖励上限或用户设置。

## 状态、保持时间与动作

下表首个动作是进入该状态时的主动作，其余是自主待机可选项。所有动作均来自原有资源；名称代表现有姿态，没有生成新立绘或新的独立摆手动画。

| 情绪 | 聊天触发后的保持时间 | 适用动作 |
| --- | --- | --- |
| 平静 | 默认状态 | 陪伴、抱尾陪伴 |
| 微笑 | 90 秒 | 开心招手、陪伴、抱尾陪伴 |
| 开心 | 6 分钟 | 开心招手、抱尾陪伴、陪伴 |
| 害羞 | 3 分钟 | 害羞傲娇、抱尾陪伴 |
| 傲娇 | 3 分钟 | 鼓脸吃醋、害羞傲娇、陪伴 |
| 困倦 | 15 分钟 | 抱枕休息、抱尾陪伴 |
| 放松 | 5 分钟 | 抱尾陪伴、陪伴 |
| 认真 | 3 分钟；番茄钟专注期间持续 | 认真工作 |
| 思考 | 2 分钟 | 认真工作、陪伴 |
| 好奇 | 2 分钟 | 陪伴、认真工作 |

## 判断规则

1. 番茄钟正在专注时，当前姿态与情绪为认真；暂停、休息或等待下一阶段时放松。原有难过/关心仍保留，朗读继续温柔安慰，结束专注后恢复尚未过期的心情。
2. 聊天中的明确情绪优先于环境：困了/晚安→困倦，放松/休息一下→放松，认真工作/专注→认真，好奇或问号→好奇，为什么/怎么以及实现/编译等技术问题→思考。明确难过、压力或生气优先于庆祝词。
3. 被夸可爱、漂亮、真棒时，亲密度低于 20% 为开心，熟悉后更容易害羞；明确说害羞则直接进入害羞。好耶、激动、太棒了→兴奋，傲娇、嘴硬→傲娇。支持常用否定短语，避免“不困”“没完成”等误判。
4. 本地时间 23:00–07:00，桌面空闲至少 90 秒时倾向困倦；无法读取桌面空闲时，使用至少 3 分钟无互动作为回退。夜间正常互动不会仅因时间立即入睡。
5. 安静 3 分钟后倾向放松；离开至少 5 分钟再回来，早期关系表现好奇，亲密度达到 50% 时倾向微笑。仍有明确聊天心情时先保留该心情。
6. 刚表达的难过、关心或生气，不会被 60 秒内的弱问候/轻度开心/害羞轻易覆盖；刚产生的明确心情也不会被 30 秒内的一句“你好”抹掉。

## 变化与自主行为

聊天心情保持上述时长，强度随剩余时间逐渐降低，结束后回到平静或符合当前情境的状态。环境变化需连续满足 15 秒，而且前一环境状态至少保持 45 秒。明确聊天与番茄钟操作立即响应。

开启右键菜单中的“按当前心情自然切换动作（20–40 秒）”后，只会在对应动作池内变化；进入新心情先展示主动作约 30 秒。操作、手动预览、语音交互期间暂停自主动作计时，结束后回到当前心情。单一可用动作（如认真工作）不会强行制造变化。保留原有平滑姿态过渡。

主动台词仍使用原来的亲密度解锁、去重、冷却、勿扰和专注保护。根据心情提高工作、休息、关心等合适话题的权重，困倦/放松时排除催工作内容。实际朗读沿用所选音色，在支持的语音服务中调整语速、音调与表达指令；最终语速限制为 0.90–1.18、音调 0.90–1.08。语音提供方和本地引擎对表达指令的支持程度可能不同。

情绪刷新不会自动打开麦克风、触发云请求、播放语音、增加聊天记录或奖励亲密度。状态栏提示当前情绪，悬停可查看本次情绪来源。

## 开发验证

`dragon_emotion_context_tests` 使用注入时钟验证分类、否定、亲密度、夜间/返回、持续与衰减、番茄钟情境、存档兼容、动作池与语音参数。`dragon_emotion_ui_tests` 运行真实 Qt 窗口，验证聊天→情绪→动作→状态标签→语音表达、真实番茄钟完成、手动动作恢复与无自动 TTS。还需运行完整 CTest、专用眨眼回归和便携包 smoke-test。所有服务测试使用本地桩，不发送真实付费请求。
