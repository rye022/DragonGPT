# DragonGPT V3.0.0

## 本次更新

V3 将按需屏幕理解、共享情境、原长期记忆和任务规划接入既有 Qt 桌宠。原 Q 版白龙娘、动作图集、台词、音色设置、关系成长和收藏保持原体系。

- 默认关闭的按需读屏：原活动窗口、窗口/显示器选择、原生窗口 helper、本地 Windows OCR、可配置图像模型到文本推理。
- 工具注册与最多8步计划、结构化校验、具体审核、顺序执行、取消/超时和有限本地只读重试。
- 复用健康、每日总结、待办、专注/喝水、剪贴板和文件预览；文件移动保留原逐项确认与撤销。
- 原表记忆去重、相反偏好确认、相关关键词检索降权；主动交互落实冷却、每日上限与忽略反馈。
- 桌面双击Q、可选组合键、屏幕快捷键与托盘；隐藏停止动画帧计时。
- 合入2.0.1剪贴板复制和显示分辨率动画缓存，保留远程已有代码。
- 新增普通每用户 EXE 安装器和完整中文用户指南。项目 README 暂缓发布。

## 安装

下载 `DragonGPT-Setup-v3.0.0-win-x64.exe`，核对随附 `SHA256SUMS.txt` 后运行。开始菜单自动创建，桌面和开机启动项可选。新数据默认存于 `%LOCALAPPDATA%\DragonGPT\UserData`；旧版便携 `data/memory.sqlite` 继续支持。升级或迁移前请退出并备份旧数据。卸载不默认删除记忆和配置。

普通运行无需 Python、Node 或开发工具。Windows OCR 需要系统识别语言；可选本机大模型和语义向量运行环境另行准备。

## 验证与限制

完整 CTest 26/26 通过；真实旧数据副本18张表内容、6个配置/凭据哈希未变化，schema7且integrity_check=ok。42个角色资源文件哈希保持不变。安装器及包依赖验证结果见 `V3_VALIDATION.md`。

首次 Windows/Qt 默认音频设备枚举在本机实测约19–20秒；这是冷启动设备阶段，不是云端语音延迟。多显示器混合DPI、受保护窗口、全屏游戏和长期运行尚需更多环境验证。未调用收费API验证云端效果；不保证主观音质或提供商账户权限。

隐私标题/密码框检测有局限，私人操作前关闭读屏。当前没有任意命令、文件删除/覆盖、系统修改或通用GUI自动化工具；文档总结限小型UTF-8文本，暂不直接解析PDF/Word。安装器没有商业代码签名。不擅自为无LICENSE原项目添加开源许可。
