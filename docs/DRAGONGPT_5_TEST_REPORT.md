2. 新养成测试最初的迁移夹具传入null source触发NOT NULL约束，改为明确fixture来源，保留产品数据库约束。
3. 首次完整新版本回归25/29通过。bond/focus测试仍寻找pre-v7备份，focus_ui仍断言总共11页；更新为schema 8和第12页，并继续校验原页位置。新状态提示曾复用历史growthStatus对象名，已改为growthCenterStatus，原“旧段落不存在”检查保留。
4. 新UI最初与SmartPage共用静态库，独立UI测试链接拉入SmartPage的窗口依赖；将纯视图独立为dragon_growth_ui，沿用同一个核心状态。后续完整构建通过。

中间失败日志保留，不将中断或部分运行记为全套通过。

## 短时性能对比

同机、相同Qt环境、独立空存档、桌宠可见，6秒预热后采样8秒。原安装桌宠在两次采样期间均保持原状态。记录的是单个被测进程，不是全系统或整套子进程开销。

| 指标 | 4.0包 | 5.0最终体验包 |
|---|---:|---:|
| CPU占单逻辑核心 | 49.36% | 39.59% |
| 平均工作集 | 172.74 MiB | 173.67 MiB |
| 平均私有内存 | 101.98 MiB | 103.38 MiB |

来源：work/performance-v4-growth-final.json、work/performance-v5-growth-acceptance.json。采样很短，CPU差异可能来自调度和缓存，不作为性能优化幅度。新增状态和视图没有在此样本中造成明显开销增加；工作集增加约0.93 MiB，私有内存增加约1.41 MiB。

从源码检查：不新增主动定时器、采样器、截图循环或大模型循环；动作每帧读取缓存的LifeState，不查数据库；成长事件与小时计数有界。新字段随交互、实际主动行为和设置修改持久化，不新增轮询写库；未获得经验的真实交互仍沿用原有lastInteraction保存。没有用全局锁包住网络调用。

## 仍需人工/外部验收

- 云端计费模型是否稳定按性格倾向表达，真实所选云音色的网络时延与故障。
- 24小时以上资源泄漏、睡眠/恢复长时状态、长期真实使用分布。
- 全屏游戏、真实会议与系统锁屏、双屏/多屏、不同DPI及硬件音频驱动。
- 真人麦克风和可选离线/浏览器/文档依赖在新系统上的安装验证。
- 用户真实存档的就地升级与正式安装器、远程Release发布。

视觉人工清单：逐个切换招手/害羞/休息/工作/抱尾，检查脸型、眉毛、眼睑、嘴部和过渡；在语音/专注过程中中断动作后检查恢复；切换半身与不同桌宠尺寸，确认气泡、剪贴板与喝水按钮不遮挡可见角色。现有自动检查与本机截图只能覆盖其中一部分。

当前限制：性格采用可解释本地规则，不是自主训练模型；共同经历需要用户确认，不自动把模型结论存为事实；探索由用户提交目标并逐项批准外部访问，不提供无限后台自主执行。
