# 本地与在线语音

## 5.0 当前配置入口

在「语音」页选择朗读引擎、音色和输出设置后保存。「打字聊天时语音回复」控制文字回复朗读；语音识别另有独立设置，详见 [5.0 完整手册](DRAGONGPT_5_MANUAL.md#语音识别与音色)。

- 旧 Qwen-TTS / 本地苏瑶 / 系统中文路径继续保留。本地生成环境需自行准备，不在轻量安装包内。
- Qwen-Audio-TTS 是独立协议，填写自己的模型 ID、对应 voice ID、地域及必要的 Workspace ID。界面提供 HTTP 业务空间、WebSocket 业务空间和 WebSocket 官方公共入口；不同入口的权限不能互相推定，程序不会自动跨入口重试。
- 模型和音色必须匹配自己的服务权限；旧协议音色名不能直接作为 Audio TTS voice ID。云端服务状态、可用模型与收费以账号控制台为准。
- 百炼 Key 与 DeepSeek Key、云 ASR Key 分开，通过 Windows DPAPI 本地保存。云合成会发送待朗读文本；真实云端授权与计费调用未包含在本次自动化发布验证中。
- 本地缓存可能包含可听见的对话，请在语音页清理和自行保管。默认数据目录及便携版兼容规则见完整手册。

以下章节记录旧版链路的实现与演进；其中历史默认值、音色列表和缓存路径不作为 5.0 云端可用性承诺，以当前界面与完整手册为准。

## v1.5 当前点击交互

桌面单击按当前可见的动作选择台词；六组各 3 句，共 18 句，文字与语音使用同一条内容。苏瑶配套 PCM 已内置；其他音色沿用缓存/在线及明确回退。完整配置与内容哈希见 assets/interaction/actions.json 和 action-manifest.json。播放期间固定被点击的动作，完成/取消后恢复自动轮换；睡眠动作不会因单击统一变成招手。

旧的 12 句通用短语仍保留为兼容资源，六个动作的桌面单击不再从该混合池选择台词。原主图静态模式只使用中性的陪伴短语。

本地中文识别（Windows SAPI）→ DeepSeek 或离线规则文字回复 → 离线模型/缓存/百炼或系统 TTS。DeepSeek 接口不承担原生实时语音，不会把 DeepSeek 密钥传给旧 OpenAI 语音服务。

## 打字回复与旧版单击语音（历史 v1.3.1）

「对话」页顶部或「语音」页的「打字聊天时语音回复」开关，默认关闭，立即保存到 data/voice.ini 的 voice/readAloud，重启保留，两处同步。当前源码沿用逐句流式朗读：已完成句子可先排队，最终 replyReady 补齐未读部分；保留换行与 Unicode。取消或关闭开关立即停止并丢弃剩余输出，不影响独立的单击短语或主动语音通话。

每次单击都会选择一句新的文字和语音，停止旧的生成/播放，没有冷却或忙碌忽略。12 句轮换，一轮内全部不同，下一轮首句与上一轮末句也不同。气泡和音频对应。苏瑶 12 句音频在发布前通过官方本地模型合成，随 EXE 资源内置；不等待加载模型，不需要 API key。其他音色先查原声缓存，未命中请求在线语音，失败明确回退内置苏瑶。内置素材不冒充其余四种原声。

百炼有效 PCM 分片到达就送入可追加的输出队列，完整结束后才写入缓存；断流/错误不会缓存残缺片段。播放器允许等待后续分片时暂时缺粮，后续音频到达会继续，不误报整句结束。取消会关闭旧流并丢弃旧数据。

快速模式默认开启，第一片或已缓冲音频耗尽后等待 4 秒仍无数据则回退系统中文。系统中文用 QtConcurrent 后台合成 WAV/PCM，通过同一 QAudioSink 输出，不依赖旧 SAPI 默认输出通知。回退会明确标注不同音色；中断的当前分段可能从段首重读，剩余文字保留。关闭快速模式仍可等待较慢的本地苏瑶。

单击使用精确定时器，在系统双击间隔之后触发；原生双击、两次普通点击组成的双击、拖动和右键会取消待触发的短语。发送新文字会停止旧输出。所有输出共用一个播放队列，不同时叠加。

这两项功能只输出声音，不启动麦克风。内置固定点击台词无冷启动；离线苏瑶新句子仍需加载/生成，其他四种音色的离线限制见下文。v1.4 增加同一 Q 版角色的六组预制姿态和淡化过渡，语音使用默认主图的平滑嘴型；不是 Live2D 分层绑定。

## 离线能力

苏瑶：官方 Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice，Serena speaker，可在本机生成新句子。官方预置列表不含 Momo、Chelsie、Bella、Katerina，因此其他四种仍不能用同款公开模型本机生成。
五种音色的云端合成结果可以保存为原声缓存，只有相同音色、相同分段文字才能命中。缓存未命中时，其他四种可先请求百炼；失败则明确提示改用离线苏瑶（非所选原声）或系统中文。
优先离线模式下，已安装的苏瑶不发送朗读文本到百炼。关闭此优先选项后，缓存未命中的新句子优先在线流式合成；快速模式失败回退系统中文，关闭快速模式可回退本地模型。

离线模型由独立 Python 子进程加载，读取固定本地模型路径；开启 HF/Transformers 离线模式并禁止 socket 连接。运行进程不接收服务密钥。应用取消或打断会终止进行中的本地生成并丢弃旧轮次；空闲约 60 秒释放进程及显存。
音频为 24 kHz PCM16，按实际播放位置计算嘴型。本机生成的音频与云端原声使用不同缓存身份，避免混淆。

## 准备与缓存

运行 offline/install.ps1 下载依赖/固定模型并做禁止网络连接的合成测试。需要 Python 3.12 x64、首次联网、数 GB 空间；NVIDIA GPU 推荐，CPU 可以运行但较慢。
解释器环境使用较短的路径，避免 Windows 长路径限制，不修改系统策略。模型和 ready.json 位于 offline-runtime；该目录不在轻量 ZIP 中。
缓存位于 data/voice-cache，约 200 MB 上限，使用音色及文字哈希作为文件名。缓存仍包含可听见的内容，可在语音设置清除；清空档案也会清除缓存。

## 云端与设备

五种在线音色仍使用 qwen3-tts-flash，需要百炼北京地域 key。在线合成发送朗读文本给阿里云；DASHSCOPE_API_KEY 或 DPAPI 文件与 DeepSeek 凭据分开。
启动不打开麦克风。点击开始语音后才识别，朗读时暂停识别避免自身回声。打断停止生成/播放并恢复聆听，结束释放麦克风。
不保存麦克风原始录音。本地识别尚未实现边播边听的声音自动打断；手动打断可用。
